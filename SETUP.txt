KSB LABS Video Studio - Setup (sirf ek baar)

1) supabase.com par free account banao > New project (naam: ksb-labs, region: Singapore/Mumbai ke qareeb).
2) Left menu: SQL Editor > New query > supabase-setup.sql ka poora text paste karo > RUN. ("Success" aana chahiye)
3) Authentication > Providers > Email: "Confirm email" OFF kar do (admin approval pehle se hai), phir Save.
4) Project Settings > API: "Project URL" aur "anon public" key copy karo.
5) config.js kholo, dono jagah paste karo, save karo.
6) chrome://extensions > is extension par Reload.
7) Extension kholo > Sign up > heartattraction5@gmail.com se account banao. Ye khud ADMIN ban jata hai.
8) Admin ke baad doosre users sign up karenge, wo "Waiting approval" mein dikhenge. Admin tab > Approve.

NOTE: service_role key kabhi kisi ko mat do aur config.js mein mat daalo.

--- v12 UPDATE (purane users ke liye) ---
A) Supabase > SQL Editor > New query > supabase-update-v12.sql ka poora text paste karo > RUN. (sirf ek baar; purana data waise hi rahega)
B) chrome://extensions > is extension par Reload.
C) Admin tab > kisi user ke saamne "Statement PDF" dabao > us user ke naam se PDF download.
D) Video banane se pehle user ko "Video Title" likhna zaroori hai (admin ko statement mein dikhega).
E) WhatsApp numbers config.js mein WHATSAPP list se badle ja sakte hain.

--- v13 UPDATE (free video + plans) ---
A) Supabase > SQL Editor > New query > supabase-update-v13.sql ka poora text paste karo > RUN. (sirf ek baar)
   Is ke baad naya signup seedha khul jata hai (approval nahi) aur sirf 1 free video milti hai.
B) chrome://extensions > is extension par Reload.
C) Free video ke baad user ko 3 plans (30 / 90 / 150 videos) nazar aate hain. Plan ke button par click karte hi
   config.js ki WHATSAPP list ka PEHLA number WhatsApp chat mein khul jata hai (plan ka naam + user ki Gmail ke sath).
D) Payment milne par Admin tab > user ke saamne "+30 Starter" / "+90 Popular" / "+150 Pro" dabao: videos user ke account mein add ho jati hain.
